# 📜 **Resumen Leyes RPA en España**

## 🏛️ **TRES LEYES CLAVE PARA RPA EN ADMINISTRACIÓN**

### **1. 📢 LEY 19/2013 de TRANSPARENCIA**
- **Qué exige**: Informar públicamente cuando uses sistemas automatizados
- **Para RPA**: Si un robot toma decisiones que afectan a ciudadanos, debes explicarlo claramente
- **Ejemplo**: "Este expediente se resuelve mediante sistema automatizado. Puede solicitar revisión humana en..."

### **2. 🔐 RGPD/LOPD - PROTECCIÓN DE DATOS**
- **Qué exige**: Evaluar impacto si tratas datos personales de forma automatizada
- **Para RPA**: Si el robot maneja datos personales → hacer **Evaluación de Impacto (EIPD)**
- **Obligatorio cuando**: Alto riesgo (muchos datos, datos sensibles, vigilancia sistemática)

### **3. ✍️ LEY 40/2015 - ADMINISTRACIÓN ELECTRÓNICA**
- **Qué exige**: Validar documentos electrónicos de forma segura
- **Para RPA**: Si el robot genera documentos oficiales → usar **Sello Electrónico o CSV**
- **CSV** = Código Seguro de Verificación (para notificaciones)
- **Sello Electrónico** = Para documentos internos de la administración

## 🎯 **RESUMEN PRÁCTICO**

| **Cuando el robot...** | **Aplica ley...** | **Hay que...** |
|----------------------|------------------|---------------|
| **Toma decisiones** que afectan ciudadanos | Ley 19/2013 | **Informar** públicamente |
| **Maneja datos personales** (DNI, dirección, etc.) | RGPD/LOPD | **Evaluar impacto** (EIPD) |
| **Genera documentos/resoluciones** oficiales | Ley 40/2015 | **Firmar con sello/CSV** |

## 💡 **CONSEJO PRÁCTICO**
**Al diseñar cualquier robot para el ayuntamiento:**
1. ✅ **Preguntar**: ¿Maneja datos personales? → RGPD  
2. ✅ **Preguntar**: ¿Genera documentos oficiales? → Ley 40/2015  
3. ✅ **Preguntar**: ¿Afecta derechos de ciudadanos? → Ley 19/2013

**Tres preguntas = Tres cumplimientos** ✅
