# **Tema 70. Protección del Acceso Remoto - Resumen Ejecutivo**

---

### **1. Concepto y Necesidad**
- **Acceso Remoto:** Capacidad de conectarse a una red, sistema o recurso interno desde una ubicación externa (teletrabajo, proveedores, movilidad).
- **Objetivo:** Habilitar el trabajo productivo **manteniendo** el mismo nivel de seguridad que dentro de la red local.

### **2. Riesgos Principales**
- **Robo de credenciales** (phishing, keyloggers).
- **Intercepción de datos** en redes no seguras (Wi-Fi públicas).
- **Dispositivos endpoint comprometidos** (malware, falta de parches).
- **Ataques a los propios sistemas de acceso remoto** (VPN, RDP).
- **Pérdida o robo de dispositivos** (portátiles, móviles).

### **3. Pilares de la Protección (Estrategia en Capas)**

#### **A. Autenticación Fuerte (MFA/2FA)**
- **Imprescindible:** Más allá de usuario y contraseña.
- **Métodos:** Token físico/software (TOTP), SMS, app autenticadora, certificados digitales, biometría.
- **Contexto:** Obligatorio para todos los usuarios, especialmente administradores.

#### **B. Canales de Comunicación Seguros**
- **VPN (Red Privada Virtual):**
  - **IPsec:** Para conexiones site-to-site. Nivel de red.
  - **SSL/TLS VPN (ej. OpenVPN, WireGuard):** Más flexibles para usuarios remotos. Nivel de aplicación.
  - **Principio del mínimo privilegio:** Asignar acceso solo a lo estrictamente necesario (segmentación de red).
- **Alternativas/Complementos:**
  - **Escritorio Remoto Seguro (RDP, VNC)** solo a través de VPN o con **gateway** (ej. Remote Desktop Gateway).
  - **SASE (Secure Access Service Edge)/Zero Trust Network Access (ZTNA):** Modelo moderno. "Nunca confíes, siempre verifica". Conecta usuarios a aplicaciones, no a la red completa.

#### **C. Endpoint Seguro**
- **Postura de seguridad obligatoria:** Antivirus actualizado, firewall personal activado, sistema operativo parcheado.
- **Discos cifrados** (BitLocker, FileVault).
- **NAC (Control de Acceso a la Red) para remotos:** Verificar estado del dispositivo antes de conceder acceso (compliance check).

#### **D. Gestión y Monitorización**
- **Logs y Auditoría:** Registrar todos los intentos de conexión (éxito/fracaso), actividad de la sesión.
- **SIEM/SOAR:** Centralizar y correlacionar logs para detección de anomalías.
- **Tiempos de sesión limitados** y desconexión automática por inactividad.

### **4. Tecnologías y Protocolos Clave**
- **Protocolos VPN:** IPsec/IKEv2, OpenVPN, WireGuard, SSL/TLS.
- **Protocolos de Autenticación:** RADIUS (a menudo con servidores como FreeRADIUS), integrado con LDAP/Active Directory.
- **Estándares de Cifrado:** AES-256 (datos), SHA-2 (integridad), RSA/ECDSA (intercambio de claves).

### **5. Marco Normativo y Buenas Prácticas (Contexto Ayuntamiento)**
- **Esquema Nacional de Seguridad (ENS):** Define requisitos para el acceso remoto (medidas como MFA, cifrado, gestión de incidentes).
- **GDPR/Protección de Datos:** El acceso remoto debe garantizar la **confidencialidad e integridad** de los datos personales.
- **Política de Seguridad Interna:** Debe definir quién, cómo, cuándo y desde dónde se permite el acceso remoto.

### **6. Recomendaciones Críticas**
1.  **Implementar siempre MFA.** Es la medida de mayor impacto.
2.  **Eliminar accesos RDP/SSH directamente expuestos a Internet.** Usar VPN o Gateway.
3.  **Segmentar la red:** Los usuarios remotos solo acceden a los recursos que necesitan.
4.  **Educar a los usuarios:** Reconocer ataques de phishing, usar redes seguras, proteger dispositivos.
5.  **Preparar un plan para dispositivos perdidos/robados:** Capacidad de borrado remoto y revocación de credenciales al instante.
6.  **Considerar modelos Zero Trust (ZTNA),** especialmente para administración de sistemas críticos o Cloud.

**Palabras Clave:** VPN, MFA (Autenticación Multifactor), Zero Trust, ZTNA, Cifrado, Endpoint, Segmentación, ENS, Auditoría.
